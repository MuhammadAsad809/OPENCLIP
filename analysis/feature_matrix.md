# Feature Matrix: FlipaClip 5.0.2 vs. Our 100% Free Animation App

| Feature Area | FlipaClip 5.0.2 Implementation | Our 100% Free Application | Implementation Strategy |
| :--- | :--- | :--- | :--- |
| **Pricing & Monetization** | Paywalls, monthly/annual subscriptions, rewarded video ads for features, banner ads, watermarks | **100% Free forever**: No ads, no subscriptions, no locked features, no watermarks | Clean-room open architecture, zero monetization hooks |
| **Project Management** | Project cards with preview thumbnails, custom name, canvas preset, FPS selector, duplication, deletion | **Full Project Gallery**: Create, rename, duplicate, delete, and instant reopen | Local Room DB + JSON metadata + cached PNG thumbnails |
| **Canvas Dimensions & Presets** | YouTube (720p, 1080p), TikTok (720x1280, 1080x1920), Instagram (1:1, 4:5), Facebook, Twitter, Custom | **Full Preset Suite**: 16:9, 9:16, 1:1, 4:3, 4:5 + Custom Width/Height up to 4K | Dynamic canvas sizing with aspect-ratio locked viewport |
| **Canvas Backgrounds** | Solid color, paper textures, scenes, camera capture, photo import | **Solid color, transparent, paper patterns, and custom photo import** | Canvas background bitmap / color composite |
| **Drawing Engine** | Skia C++ in `libfc.so` via `DrawTool`, dynamic brush stamps (`.fcb`), pressure curves | **Hardware-accelerated Android Canvas / Custom View Engine** with Bézier stroke smoothing | Quadratic Bézier curve interpolation (`quadTo`) with velocity/pressure width dynamics |
| **Brush Variety** | Pen, Pencil, Highlighter, Brush, Crayon, Airbrush | **Pen, Pencil, Brush, Airbrush, Marker, Highlighter, Crayon** | Configurable `Paint` shaders, stamp textures, stroke cap/join, and alpha blending |
| **Eraser** | Configurable size, hardness/feathering, opacity | **Full Eraser Tool**: Configurable size, feathering/hardness, opacity | `PorterDuff.Mode.CLEAR` / `PorterDuffXfermode` drawing |
| **Ruler / Geometry Tools** | Line, Oval, Rectangle/Square, Mirror | **Straight Line, Circle/Oval, Rectangle, Symmetry/Mirror** | Geometric guides projecting touch events onto geometric paths |
| **Color Picker** | HSV color wheel, alpha slider, palette presets, eyedropper tool | **Full HSV Color Wheel, Alpha Slider, Swatch Palette, Eyedropper** | Color wheel picker + magnifying loupe eyedropper sampling pixels |
| **Selection / Transform (Lasso)** | Lasso path selection, rotate, scale, flip horizontally/vertically, move, stamp, delete | **Freehand Lasso Tool**: Select bounding box, translate, pinch-to-scale, rotate, flip, copy, cut, delete | Path hit-testing, Bitmap clipping mask, Matrix transformation |
| **Fill Bucket** | Flood fill with configurable tolerance threshold | **Scanline Flood Fill**: Tap to fill bounded areas with tolerance | Optimized 4-way scanline queue fill on Bitmap pixel array |
| **Frame Management** | Bottom frame thumbnail carousel, add frame (`+`), clone frame, paste frame, delete frame, reorder frames | **Interactive Bottom Frame Timeline**: Add, duplicate, delete, reorder, thumbnail previews | `LazyRow` Compose timeline / RecyclerView with LRU thumbnail cache |
| **Layers Engine** | Multi-layer (capped at 3 for free users, up to 10 for Plus), visibility toggle, opacity, blend modes, alpha lock, clipping mask | **Unlimited Layers (No artificial caps)**: Add, reorder, visibility toggle, opacity slider, lock, blend modes | Independent layer Bitmaps composited onto frame surface |
| **Onion Skinning** | Before/after frames (1-5), configurable opacity gradient, colored onion mode (Red previous, Green next) | **Complete Onion Skin Engine**: Configurable frames (1-5 before, 1-5 after), opacity falloff, Red/Green colored tinting | ColorMatrix / PorterDuff tint filtering composited behind active frame |
| **Playback & Timing** | Real-time loop playback, 1 to 30 FPS, scrub bar, frame counter | **Real-Time Playback**: 1 to 30 FPS, loop toggle, frame counter, scrubbing | Choreographer / Coroutine ticker with frame-rate regulation |
| **Undo / Redo** | Deep history stack in `libfc.so` (`Fc2EventsManager`) | **Robust Command-based Undo/Redo**: Stroke undo, layer action undo, frame action undo | Command stack storing layer delta snapshots with memory recycling |
| **Audio Tracks** | Multi-track audio, recording, waveform rendering, trimming, synchronized playback | **Audio Import & Timeline Sync**: Import MP3/WAV, preview playback in sync with animation | `MediaPlayer` / `SoundPool` synchronized to frame index |
| **Export Formats** | MP4 (H.264), Animated GIF, PNG Sequence (Watermark added unless paid) | **MP4 (H.264), Animated GIF, PNG Sequence, Single Frame PNG (Zero Watermarks)** | Native `MediaCodec` + `MediaMuxer` for MP4, custom GIF encoder, PNG writer |
| **Storage & Privacy** | Private SQLite + `.fci` files, proprietary `.fc` backup format | **Clean Local Storage**: Standard JSON metadata + standard PNG frame layers + `.zip` project backups | Scoped storage / app-private files, 100% offline-first |
